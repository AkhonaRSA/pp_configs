### 8. Performance Optimization & Speed Acceleration Engine
To resolve sluggish frame rates and eliminate browser memory pressure, the following critical optimizations were engineered:
- **WebGL Context Reduction (17 Contexts → 2 Contexts):**
  - Previously, `Tech.jsx` rendered 13 simultaneous `<Canvas>` elements, and `App.jsx` rendered 3 duplicate `<StarsCanvas>` instances. This exceeded browser WebGL context limits (causing context loss and frame drops).
  - Consolidated `Tech.jsx` into a unified, high-performance interactive 3D Sphere Showcase that dynamically projects the selected technology with full OrbitControls on a single WebGL context.
  - Consolidated the 3D starfield into a single, persistent ambient `StarsCanvas` fixed at the root level, spanning seamlessly from top to bottom.
- **Rollup Chunk Splitting & Payload Reduction:**
  - Configured `vite.config.js` with `manualChunks` to split vendor dependencies:
    - `index.js` payload was reduced by **>90%** from **1,180 kB down to 98.91 kB**!
    - Heavy libraries isolated into dedicated parallel-loading cacheable chunks: `three-vendor`, `react-three-vendor`, and `motion-vendor`.
- **GPU Fragment & Vertex Optimization:**
  - Removed unnecessary real-time shadow map calculation passes from `EarthCanvas`.
  - Tuned device pixel ratio (`dpr={[1, 1.25]}`) to prevent 4x over-shading on high-density Retina screens.
  - Enabled hardware `powerPreference: "high-performance"` and disabled unused MSAA passes on starfield point clouds.
- **Hardware Layer Promotion:**
  - Applied GPU transform acceleration (`transform-gpu`, `will-change-transform`) across interactive technology cards to eliminate layout reflows during fast scrolling.

## 6. How to Run Locally

### Prerequisites
- Node.js `v18.0.0` or higher
- npm `v9.0.0` or higher

### Commands
```bash
# 1. Navigate to the project directory
cd c:/usr/amportfolio/pp_configs

# 2. Install dependencies (if not already installed)
npm install

# 3. Start local development server
npm run dev

# 4. Create production build
npm run build

# 5. Preview production build locally
```
